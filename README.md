# Mahima Yusuf Tarana — Research Portfolio

Responsive static research portfolio with one front page, one research-experience hub, and the seven user-supplied case-study/academic pages.

## To view / publish
- Open `index.html` in a browser (with files unpacked in the same folder).
- Publish the entire folder to GitHub Pages, Netlify, or any static host without changing internal filenames.
- `experience-nsu.html` links each employment period to the appropriate related research.
- All case-study pages preserve the user-provided designs, with a minimal appended navigation trail.

## Page map

- `index.html` — profile, highlights, selected studies, experience, publications, education, contact
- `experience-nsu.html` — Research Associate (SURF-IT), Research Assistant (NSU), Research Assistant (University of Dhaka)
- `project-lidar-embankment.html` — SURF-IT LiDAR and embankment mapping
- `project-lulc-segment-analysis.html` — SURF-IT land cover and river/land side percentage extraction
- `project-ultra-poverty-vulnerability.html` — SURF-IT ultra-poverty publication
- `project-vae3-inundation.html` — SURF-IT experimental inundation forecast
- `project-karnaphuli-water-quality.html` — NSU Research Assistant project
- `academic-theses.html` — MSc & BSc studies, related to DU research
- `training-credentials-recognition.html` — training, courses, language and awards
